# Same Room — STEP 7 media payload

Procedural poster/key-art files and self-contained Tier B trailer recorders. `TEAM_NAME` and `EVENT_NAME` are intentionally blank.

## Trailer recorder (Tier B)

- Open `SameRoom_TrailerRecorder_EN.html` or `SameRoom_TrailerRecorder_FA.html` in current Google Chrome.
- Click **Start recording** / **شروع ضبط** once.
- Keep the Chrome tab open and visible for about 48 seconds. The page automatically downloads a 1920×1080, 30 fps WebM; if automatic download is blocked, click the download link that appears.
- These are recorder pages, not pre-rendered videos; no MP4 is included. A real Chrome recording/playback test was not available in the build environment.
- The Persian recorder localizes the cards and end card. The embedded repository game copy itself is English-only.
- The cloned game source has no in-game audio system. The recorder adds an original synthesized ambient bed and event cues; these are not game audio.

All artwork is procedurally drawn. No AI-generated imagery, external assets, network requests, third-party music, team name, or event name are included.
